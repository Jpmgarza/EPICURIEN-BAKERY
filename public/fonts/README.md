# Font Files

Add Satoshi font files here:

1. Download from [Fontshare](https://www.fontshare.com/fonts/satoshi)
2. Place these files in this directory:
   - `Satoshi-Regular.woff2` (weight 400 — body text)
   - `Satoshi-Medium.woff2` (weight 500 — H2/H3 headings)

These are referenced in `src/app/layout.tsx` via `next/font/local`.
